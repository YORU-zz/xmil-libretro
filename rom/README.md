# 同梱 IPL ROM について

`X1_compatible_rom.bin` は、meister68k 氏（Meister）の
**X1 compatible ROM ver 0.7.3** です。

- ライセンス： **CC0 1.0 Universal**
- 実機の IPL ROM とは無関係にフルスクラッチで実装された互換 IPL で、
  FDD／CMT／BASIC ROM 等からの起動に対応します。
- 使い方： RetroArch の system ディレクトリ内 `xmil/IPLROM.X1` として
  配置してください。
- SHA-256: 59d3c278c8f7f911e0e7f48906508d93e5c52877a9510083ae577b6ea865763a
