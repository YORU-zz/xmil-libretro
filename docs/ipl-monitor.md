# 互換 IPL 内蔵モニタの使い方

同梱の X1 互換 IPL ROM（meister68k 氏、CC0）には、簡単なマシン語モニタが内蔵されています。この文書は、そのコマンドの一覧です（IPL ROM のソースコードに基づきます）。

## モニタへの入り方

IPL のブートデバイス選択メニューで **M** キーを押すと、モニタに入ります。プロンプトは `*` です。

なお、ブートデバイス選択メニューで使えるキーは次のとおりです。

- `0`〜`3`：フロッピードライブから起動
- `E`：EMM から起動
- `R`：BASIC ROM から起動
- `C`：CMT（テープ）から起動
- `M`：モニタ

モニタに入る時、テキスト画面は消去されますが、グラフィック画面は消去されません。そのため、グラフィック VRAM に残っていた内容がドット模様として重なって見えることがあります。実害はありません。

## コマンド

コマンドは大文字・小文字を区別しません。アドレスは16進数で指定します。

- `D [アドレス]`：メモリダンプ。128バイトを16行で表示します（1行＝8バイトの16進表示＋「/」＋文字表示）。アドレスを省略すると、前回の続きから表示します
- `E アドレス`：メモリの書き換え。`アドレス: 現在の値` と表示されるので、2桁の16進数を入力すると書き換えて次のアドレスへ進みます。空行（Enter のみ）では書き換えずに次へ進みます。16進数として読めない入力をすると、モニタのプロンプトに戻ります
- `G アドレス`：ROM を切り替えないまま、指定アドレスのルーチンを呼び出します。ルーチンが RET で戻ると、モニタに帰ってきます
- `J アドレス`：メモリマップをオール RAM に切り替えてから、指定アドレスへジャンプします。低位アドレスに RAM が必要なプログラム用です。モニタには戻りません
- `B [デバイス]`：指定デバイスの先頭セクタ（ブートセクタ）を読み込みます。デバイスの指定はブートメニューと同じです（`0`〜`3`＝FD、`E`＝EMM、`R`＝ROM、`C`＝CMT）
- `#`：画面を消去します
- `R`：モニタを終了し、IPL のブートデバイス選択メニューに戻ります

## 注意

- モニタから TapeOS に直接戻るコマンドはありません。TapeOS を起動し直すには、`R` でメニューに戻ってから FD ブートを選ぶか、エミュレータ側でリセット／再読み込みをしてください。
- `E` での書き換えや `J` でのジャンプは、IPL やメモリ上の内容を直接操作します。実行中の TapeOS に戻る前提では使わないでください。
