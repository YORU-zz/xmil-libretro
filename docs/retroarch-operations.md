# RetroArch 最低限の操作（TapeOS を動かすために）

TapeOS（xmil コア）を RetroArch で動かすための、最低限の操作だけをまとめたものです。困った時の対処は、別の文書「RetroArch でうまく動かなかった時に（TapeOS 編）」を見てください。

## 起動と読み込み

- メニューから：**コアをロード** で xmil を選び、**コンテンツをロード** で `shell.d88` などのイメージを選びます。
- コマンドラインから：`retroarch -L <コアの場所>/x1_libretro.so <イメージの場所>` でも起動できます。

## ゲームフォーカス（キーボードの渡し方）

X1 のようなキーボードを使うコアでは、**ゲームフォーカス**が要ります。ON の間はキーボードがまるごとコアに渡り、RetroArch のホットキーは効きません。

- ON/OFF の切替：**Scroll Lock** キー
- 起動時から ON にする：設定 `input_auto_game_focus = "1"`（起動スクリプトに `--appendconfig` で差し込むこともできます）

フォーカスが ON の間は、メニューや全画面切替などの操作はできません。まず Scroll Lock でフォーカスを切ってから操作します。

## 全画面とメニュー

- 全画面の切替：フォーカスを切った状態で **F**
- メニューを開く：フォーカスを切った状態で **F1**

## 終了

- **ESC を2回**で RetroArch が終了します。エミュレータ実行中に押してもホストに戻ります。

## ディスクの交換

TapeOS のシェル起動後に別のディスクを使いたい場合は、RetroArch のディスクコントロール（メニュー内のディスクイメージの差し替え）で .d88 を入れ替えます。
